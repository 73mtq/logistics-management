# 快递助手 1.2.0 开发预发布

日期：2026-11-27。包名 `com.logisticsmanagement.app`，versionCode `3`，最低 Android API 26，Room schema v2。使用本机 release keystore 签名。

## 当前范围

四个平台订单与物流汇总，包裹列表与详情、筛选与搜索、日历、备注与归档、账号添加、登录、启停与移除，后台更新调度。S7 在真实生产库上完成页面覆盖：26 件已签收包裹、商品名与运单尾号搜索、状态筛选、平台与账号筛选、空结果提示；京东包裹详情（复制运单号、25 条轨迹、备注保存与恢复、归档与恢复）；日历当天物流更新 3 件与日期选择；设置页 3 个账号卡片与自动更新开关。页面数值与数据库副本逐项一致。

未覆盖：取件码复制（生产库没有待取件包裹与取件码）、未关联抖音订单卡片与待发货订单卡片（没有对应真实订单）；S6 遗留的真实抖音账号移除、按账号证据目录清理、WorkManager 实际执行、京东重新登录、已加载 profile 的延迟删除继续保留。详细范围见[验收记录](../acceptance.md)。

## 自 1.1.0 起的变化

- 抖音账号统一为 App 页面采集，采集状态、进度恢复、轮次与资料保留规则完善；商城订单列表按卡片“更多”→“查看物流”读取物流。
- 淘宝、拼多多、京东完成短信会话恢复与订单物流读取；京东订单页迁移到 o.m.jd.com 与 newUserAllOrderList，物流读取使用 orderTrackBusiness。
- 账号移除清理凭据、profile 与原生进度，业务记录保留；后台更新登记与取消有系统侧记录。
- 版本更新为 1.2.0、versionCode 3，并完成页面覆盖与发布流程。
