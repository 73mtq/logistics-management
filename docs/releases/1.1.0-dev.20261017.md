# 快递助手 1.1.0 开发预发布

日期：2026-10-17。包名 `com.logisticsmanagement.app`，versionCode `2`，最低 Android API 26，Room schema v2。使用既有调试签名。

## 当前范围

四个平台订单与物流汇总、包裹筛选与搜索、日历、备注和归档。网页账号使用独立 profile；同步保留已提交资料及待查询进度。抖音已验证一个已签收订单导入和物流关联、停止继续及进程重启恢复。

完整业务验收保持未完成。京东、淘宝部分范围，抖音完整列表、自动重连、部分候选字段，以及缺少样本的数据和系统场景继续保留。详细范围见[验收记录](../acceptance.md)。

项目暂停功能开发，现有实现、账号、profile及本机证据保留；后续顺序见[开发计划](../development-plan.md)。
