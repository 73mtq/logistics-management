# 后续阶段的 Jev 辅助规则

T15及之后新建阶段默认包含Jev辅助判断。每阶段在执行记录中明确输入、用途、来源和验证条件，沿用逐阶段授权、验收和结束安排。

## 判断与执行

固定使用 `jev-1.14.0`。页面用途、相关资料选择、失败分类及文档证据核查使用预先定义的选项，包含资料不足和无法确定。每个问题独立且具有充分上下文，独立问题批量提交；问题编号用于关联本机记录。

文档辅助采用SUPPORTED、CONTRADICTED、INSUFFICIENT、UNCERTAIN四分类。保存来源、陈述、模型概率及逐项核查结果。数据库归属、日期、事务、构建、签名和验收结论通过代码、工具及原始资料确定。

页面自动操作保留至少0.95概率和当前官方窗口、目标节点、父节点及实际范围检查。禁止交易操作。模型判断及网页节点变化时重新核查，正常触摸导航期间停止自动点击。

## 隐私、期限和成本

发送公共标签、必要结构和经过处理的摘要；账号、订单、运单、地址及凭据使用请求内编号替代。完整原文和编号映射保存在本机。凭据经现有加密入口保存，命令输出不包含凭据。

单次请求十秒，每阶段最多一百次。相同模型、问题和输入通过指纹复用结果；失败请求也计入请求上限。记录真实请求数、缓存数、耗时、输入输出tokens及费用估算，明确计费依据和统计范围。

错误或不确定项保存具体条件，并保持未完成。模型版本变化需要重新验证。程序错误在发生位置暴露，明确外部失败按现有方式展示。

## 验证和记录

使用真实记录，保持原始资料。分开记录判断一致性、达到采用门槛的结果、需要重新核查的条目和缺少样本的类别。模型输出经过复核后才用于具体工作。

整体提速或人工介入改善需要同条件比较。T15九项资料核查中七项一致，达到0.95的五项一致；九项均已按原始资料完成复核，模型差异由源码和原始记录核查。当前没有整体效果对照，这些结果限定于本次小规模资料。

阶段目录保存输入摘要、来源索引、请求及响应、缓存、逐项核查、费用和未完成范围。阶段结束更新主状态和交接入口，后续任务继续沿用现有账号、profile及有效配置。
